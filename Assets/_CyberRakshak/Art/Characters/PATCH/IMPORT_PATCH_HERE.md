# PATCH Model Import

Place the Meshy export for PATCH in this folder.

Preferred files:

- `PATCH.glb` or `PATCH.fbx`
- texture files, if Meshy exports them separately

Import checklist in Unity:

1. Drag the Meshy model into this folder.
2. Select the model and set scale if needed.
3. Create a prefab under `Assets/_CyberRakshak/Prefabs/Characters/PATCH`.
4. Add `PatchCompanion` to the prefab.
5. Assign Adi/player as the `Target` when the level starts.
6. Keep PATCH hovering near the player shoulder for the first prototype.

# GDD Implementation Track

This file is the bridge between the GDD and Unity work. It will be updated once the GDD is available.

## Assumed Current Project Spine

CyberRakshak XR teaches ethical-hacker thinking through a story-driven game where the player learns to identify risky digital behavior, choose ethical actions, and receive feedback from PATCH.

## First Vertical Slice

1. Player enters a training scenario.
2. PATCH introduces the situation.
3. Player explores a small environment.
4. Player finds suspicious digital objects or prompts.
5. Player chooses between safe, unsafe, and ethically questionable actions.
6. Game gives immediate feedback.
7. Session result is logged for learning analytics.

## Systems To Build First

- Player controller.
- Interaction prompt.
- Scenario objective tracker.
- Ethical choice data model.
- Feedback panel.
- Basic scoring.
- Attempt analytics record.
- PATCH dialogue trigger.

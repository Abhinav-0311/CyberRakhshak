# CyberRakshak XR Agent Notes

## Current Direction

Build a Unity game based on the GDD. The project framing is ethical hacking, not generic cybersecurity.

## Engineering Rules

- Keep all owned assets inside `Assets/_CyberRakshak`.
- Use the `CyberRakshak` namespace for C#.
- Keep mechanics small and testable before adding visual polish.
- Prefer ScriptableObjects for authored game data such as tasks, ethical choices, dialogue snippets, objectives, scoring rules, and lesson metadata.
- Do not add large binary assets unless the user asks or provides them.
- Preserve Unity-generated files and user-created scenes.

## Capstone Constraints

- Target a one-year capstone deliverable from July 2026 to March 2027.
- Prioritize a polished playable vertical slice over a broad but shallow prototype.
- Maintain evidence for review: design notes, screenshots, evaluation plan, and implementation progress.
- Keep conference/journal/IGDC outcome in mind while planning evaluation and documentation.
